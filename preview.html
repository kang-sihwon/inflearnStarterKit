Starter Kit
Monorepo Starter

Next.js + Express 스타터킷

프론트엔드와 백엔드를 한 저장소에서 바로 시작하세요.

구성

Next.js 15

App Router, TypeScript, Tailwind CSS v4

shadcn/ui

다크 모드, 반응형 헤더/푸터 레이아웃

Express API

zod 검증, 에러 핸들링, 라우터 구조

상태 관리

Zustand + TanStack Query

폴더 구조

apps/
├─ web/   Next.js 15 + Tailwind + shadcn/ui
│  └─ src/app (/, /todos, /about) · components · lib/api.ts · stores
└─ api/   Express + TypeScript
   └─ src/config · middlewares · routes · utils

시작하기

npm install
npm run dev   # web :3000 · api :4000

스크립트

npm run devweb + api 동시 실행
npm run dev:web / dev:api개별 실행
npm run buildapi, web 순서로 빌드
npm run lint / typecheck전체 검사

API 엔드포인트

GET /api/health서버 상태
GET /api/todos목록 조회
POST /api/todos생성 {"title": "..."}
PATCH /api/todos/:id수정
DELETE /api/todos/:id삭제
